# Bhukya Akhil - Personal Portfolio

A customized React portfolio for **Bhukya Akhil**, Software Development Engineer – Backend.

## Stack

- React
- React Bootstrap
- Bootstrap Icons
- Animate.css
- React Multi Carousel

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000

## Sections

- Home
- Technical Skills
- Projects
- Professional Experience
- Education & Certifications
- Contact

The resume is available at `public/Akhil_Bhukya_Resume.pdf` and is linked from the home section.
